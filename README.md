Full-stack developer working mostly in React, TypeScript and Django. I build and run

## What I'm working on

![The Uma Carat Calculator planner](https://raw.githubusercontent.com/charlesmerriman/uma-carat-calculator-web/develop/docs/images/planner.webp)

**Uma Carat Calculator**: players enter what they hold and what they want to pull for, and it
projects their in-game currency forward to each banner, so they know before they spend.

- [uma-carat-calculator-web](https://github.com/charlesmerriman/uma-carat-calculator-web): React 19, TypeScript, Vite, Tailwind, prerendered for search and link previews
- [uma-carat-calculator-api](https://github.com/charlesmerriman/uma-carat-calculator-api): Django 6, Django REST Framework, PostgreSQL, OAuth sign-in with no stored profile data

I built it and maintain it, with a small team keeping the game content current: about 340 merged pull requests,
3,000+ automated tests across the two repos, and continuous deployment on DigitalOcean.
